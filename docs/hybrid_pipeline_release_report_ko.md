# 하이브리드 개인정보 탐지 파이프라인 검증 보고서

## 결론

이번 배포 대상은 하나의 NER 모델이 아니라 기존 탐지 파이프라인에 Frame·Koredact·AtonLee·Seongyeon, 규칙 탐지, 공식 주소 사전, 금융결제원 계좌번호 체계 근거, 문맥·경계·겹침 후처리를 결합한 하이브리드 파이프라인이다.

예측 전에 정답과 평가 기준을 봉인한 신규 장문 세트에서 배포 기준을 모두 통과했다. 운영 패키지로 정리한 코드의 raw 예측, 최종 선택 span, 실제 마스킹 결과도 평가 실행 결과와 일치했다.

## 독립 장문 평가

- 문서 12건, 총 27,837자, 문서당 33~35줄
- 기존 개발 주소와 겹치지 않는 공식 동·도로 조합 12개
- 개인정보 정답 156개, 일반정보 decoy 156개
- 전체 보호 156, 부분 보호 0, 미탐 0
- 일반정보 오탐 0, 정답 밖 과마스킹 문자 0
- raw 및 최종 결과의 exact 중복 0
- raw 및 최종 결과의 겹침 0
- 유형·경계 exact: TP 156, FP 0, FN 0, F1 1.0
- 평균 503.39ms, p50 489.21ms, p95 666.53ms, 초당 약 4,608자

## 지원 유형

각 유형에서 12/12 전체 보호와 12/12 유형·경계 exact를 확인했다.

- 이름
- 상세 주소
- 계좌번호
- 생년월일
- 사용자명
- 여권번호
- 운전면허번호
- 차량번호
- 신용카드번호
- 이메일 주소
- IPv4 주소
- 한국 전화번호
- 주민등록번호

## 경계 및 겹침 확인

주소 뒤의 배송 지시나 일반 문장은 보존하며 행 끝까지 무조건 확장하지 않는다. raw 결과와 실제 마스킹 결과를 모두 저장해 중복, 같은 라벨 겹침, 다른 라벨 겹침, 정답 밖 마스킹을 별도로 확인했다. 최종 봉인 세트에서는 모든 값이 0이었다.

## 회귀 확인

- 기능별 과거 회귀 세트: 총 1,014/1,014 전체 보호
- 기존 공개 기본 정책 검사: 115/115 통과
- 기능 중심 이름으로 정리한 패키지와 배포 평가 출력: 12문서 raw·selected·masked 불일치 0

기능별 과거 결과는 `evaluation/historical_regression_summary.json`, 기존 공개 검사 결과는 `evaluation/existing_suite_regression.json`에 저장했다.

## 해석상 주의사항

- 이번 마지막 평가는 하이브리드 파이프라인만 대상으로 했다.
- 과거 단독 모델 실행기는 라벨 매핑과 후처리 계약이 달라 직접적인 우열 근거로 사용하지 않는다.
- 합성 독립 세트 통과는 실서비스 전체 분포에서의 무오류를 보장하지 않는다.
- 모델 가중치, 실제 개인정보, 서버 전용 환경 설정과 주소 DB는 저장소에 포함하지 않는다.

원시 예측과 실제 마스킹을 포함한 증적은 `evaluation/long_document_generalization/`에서 확인할 수 있다.
